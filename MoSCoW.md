**## MoSCoW Prioritization**

| Priority            | Features                                                                                                                                                                                                                                                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Must Have (M)**   | Upload React/JSX source code, Parse source code into AST, Perform AST-based accessibility analysis, Detect missing image alt text, Detect unlabeled form controls, Detect heading hierarchy issues, Detect semantic HTML issues, Detect keyboard accessibility issues, Generate accessibility score, Display structured accessibility report |
| **Should Have (S)** | Classify issues by severity, Provide developer-friendly explanations, Recommend remediation guidance, Display relevant WCAG 2.2 references, Analyze a webpage using a URL, Export accessibility reports                                                                                                                                      |
| **Could Have (C)**  | Save scan history, Filter issues by severity or category, Accessibility dashboard with summary statistics, Compare previous scan results, Dark mode                                                                                                                                                                                          |
| **Won't Have (W)**  | Automatic code repair, AI-generated fixes, User authentication, Team collaboration, Full website crawling, Browser extension, CI/CD integration                                                                                                                                                                                              |
